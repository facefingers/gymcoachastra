## 📱 ШАГ 2: ОТКРОЙ НА ТЕЛЕФОНЕ

### **2.1 Открой в Chrome:**

1. На телефоне открой **Chrome** (обязательно Chrome!)
2. Введи свою ссылку:

   ```
   https://ТВОЙ-USERNAME.github.io/workout-tracker/
   ```

### **2.2 Установи как приложение (PWA):**

**Вариант А: Через меню Chrome**

1. Нажми **⋮** (три точки) в правом верхнем углу
2. Нажми **"Добавить на главный экран"** или **"Install app"**
3. Выбери название (например "Тренировки")
4. **Добавить**

**Вариант Б: Через всплывающий баннер**

1. Когда открываешь сайт, внизу появится баннер
2. **"Добавить на главный экран"**
3. Готово!

## 🆘 ЕСЛИ НЕ РАБОТАЕТ

### **Проблема: "Страница не найдена 404"**

**Решение:**
1. Проверь что GitHub Pages включен (Settings → Pages)
2. Проверь что ветка **main** выбрана
3. Подожди 2-3 минуты после включения
4. Проверь правильность ссылки

---

### **Проблема: "Не предлагает установить"**

**Решение:**
1. Открывай **только в Chrome** (не Safari, не Firefox!)
2. Проверь что открыл через **HTTPS** (не HTTP!)
3. Проверь что все файлы загружены (особенно `manifest.json`)
4. Попробуй: Chrome → ⋮ → **"Добавить на главный экран"** вручную

---

### **Проблема: "Не работает офлайн"**

**Решение:**
1. Открой приложение **с интернетом** первый раз
2. Подожди пока всё загрузится
3. Проверь: Chrome → ⋮ → **История** → **Очистить данные**
4. Открой заново → Service Worker зарегистрируется
